# 🎮 坦克大战 (Tank Battle)

经典FC坦克大战游戏的HTML5复刻版本。

![Tank Battle](https://img.shields.io/badge/Game-Tank%20Battle-red?style=for-the-badge)

## 游戏特色

- 🎯 经典坦克大战玩法
- 🎨 现代化视觉效果
- 🎮 流畅的操控体验
- 📈 关卡系统，难度递增
- 💥 爆炸特效

## 如何游玩

### 在线游玩
直接打开 `index.html` 文件即可开始游戏！

### 操作方式

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` / `J` | 发射子弹 |

## 游戏规则

1. 🎯 **目标**: 消灭所有敌人坦克，保护你的基地
2. ❤️ **生命**: 初始3条生命，被击中会损失生命
3. 🏆 **得分**: 每消灭一个敌人得100分
4. 📊 **关卡**: 消灭所有敌人后进入下一关，敌人数量会增加

## 地图元素

| 元素 | 说明 |
|------|------|
| 🧱 砖墙 | 可以被子弹摧毁 |
| 🔩 钢墙 | 无法被摧毁 |
| 🟡 基地 | 必须保护，被摧毁则游戏结束 |
| ⬛ 空地 | 可以自由通行 |

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
- CSS3

## 本地运行

1. 克隆仓库
```bash
git clone https://github.com/你的用户名/tank-battle.git
```

2. 打开 `index.html` 文件

就这么简单！无需安装任何依赖。
